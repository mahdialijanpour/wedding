# کارت عروسی حدیث و حسن

پروژهٔ React + Vite با طراحی راست‌به‌چپ، فونت ایران‌نستعلیق، عکس ادیت‌شده، دو صفحهٔ متحرک و نمایش واکنش‌گرا. ابتدا دکمهٔ پلی داخل خود کارت دیده می‌شود؛ با لمس آن، موسیقی و نمایش دعوت‌نامه آغاز می‌شوند.

## اجرا

Node.js نسخهٔ 22.12 یا جدیدتر نصب باشد. در پوشهٔ پروژه اجرا کنید:

```sh
npm install
npm run dev
```

سپس نشانی `http://localhost:5173` را باز کنید. برای نمایش روی گوشی در شبکهٔ مشترک، از نشانی Network که Vite در ترمینال نشان می‌دهد استفاده کنید؛ دسترسی به این نشانی به تنظیمات فایروال سیستم نیز بستگی دارد.

## خروجی قابل استقرار

```sh
npm run build
npm run preview
```

خروجی پوشهٔ `dist` را روی میزبانی استاتیک قرار دهید. مسیر پایهٔ نسبی تنظیم شده تا پروژه در زیرپوشه هم اجرا شود. برای مشاهدهٔ خروجی ساخت از سرور preview استفاده کنید؛ باز کردن مستقیم `dist/index.html` با file:// روش اجرای این پروژه نیست.

## تغییر محتوا

- نام‌ها، شعر، تاریخ، ساعت و آدرس: `src/data/invitation.js`
- نام‌های کوچک بالا و نام‌های خانوادگی پایین: `firstNames` و `familyNames` در فایل اطلاعات مراسم
- عکس فعلی: `src/assets/childhood-portrait-supplied.jpg`؛ عکس ارسالی کاربر با لباس عروس و داماد. نسخه‌های قبلی نیز حفظ شده‌اند
- آهنگ: `src/assets/babe-delami.mp3`؛ ثانیهٔ شروع و بلندی صدا در `music` در فایل اطلاعات مراسم
- ظاهر و اندازه‌ها: `src/styles.css`
- اجزای کارت: `src/components/InvitationCard.jsx`
- زمان‌بندی و کنترل پخش: `src/hooks/usePlayback.js`

مقدار `time` فعلاً خالی است چون ساعت مراسم اعلام نشده. با وارد کردن متن ساعت، آن قسمت روی کارت ظاهر می‌شود. تاریخ فارسی، `iso` و آرایهٔ میلادی را هنگام تغییر تاریخ با هم اصلاح کنید. کد QR از `mapQuery` تولید می‌شود و جستجوی تالار را باز می‌کند، نه مختصات تأییدشدهٔ یک محل.

تا پیش از زدن دکمهٔ «پخش دعوت‌نامه»، عکس و نوشته‌ها پنهان‌اند و زمان‌بندی کارت جلو نمی‌رود. با شروع واقعی پخش موسیقی، دکمه کنار می‌رود و عکس طی ۳٫۲ ثانیه با افزایش تدریجی وضوح، محوشدگی و زوم نرم ظاهر می‌شود؛ بعد از ورود، عکس ثابت می‌ماند. نوشته‌ها با ۲٫۶ ثانیه تأخیر نسبت به شروع عکس نمایان می‌شوند. نام «حدیث و حسن» در بالا، سه خط شعر در مرکز و «نگین راز و صفافر» در پایین سمت چپ صفحهٔ اول نمایش داده می‌شود. کارت در پایان روی صفحهٔ جزئیات می‌ماند. تنظیم کاهش حرکت مرورگر، حرکت و زوم عکس و افکت نوشتن متن را غیرفعال می‌کند. برای تماشای دوبارهٔ توالی، صفحه را تازه‌سازی کنید و دکمهٔ پلی را بزنید.

آهنگ «باب دلمی» محسن چاوشی با زدن دکمه از ثانیهٔ ۱۲ خود آهنگ پخش می‌شود. پیش از این کلیک، درخواست پخش خودکار انجام نمی‌شود. موقعیت پخش ذخیره نمی‌شود؛ رفرش کارت را به صفحهٔ دکمهٔ پلی برمی‌گرداند و شروع بعدی دوباره از ثانیهٔ ۱۲ است. موسیقی پس از نمایش کامل جزئیات ادامه دارد و در پایان فایل دوباره از ثانیهٔ ۱۲ پخش می‌شود، بدون اینکه نمایش کارت از اول شروع شود. نوار زمان یا دکمه‌ای خارج از کارت وجود ندارد.

دکمه با لمس، کلیک و کلیدهای Enter یا Space کار می‌کند. فراخوانی `play()` مستقیماً در رویداد دکمه انجام می‌شود تا اجازهٔ تعامل کاربر حفظ شود. اگر آهنگ هنوز بارگذاری نشده باشد، دکمه حالت انتظار دارد و نمایش عکس و نوشته‌ها تا شروع پخش صبر می‌کند. در صورت خطا، پیام نمایش داده می‌شود و امکان تلاش دوباره وجود دارد. همهٔ عکس‌ها، فونت‌ها و فایل آهنگ داخل پروژه هستند؛ فقط باز کردن نقشه به اینترنت نیاز دارد.
