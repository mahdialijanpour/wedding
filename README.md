# دعوت‌نامهٔ عروسی سینا و نادیا

React + Vite، راست‌به‌چپ، مناسب موبایل و دسکتاپ.

```sh
npm install
npm run dev
npm run build
```

در صورت اشغال بودن پورت پیش‌فرض:

```sh
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5187 --strictPort
```

اطلاعات مراسم در `src/config.js` قرار دارد. تاریخ اصلی شنبه ۷ آذر ۱۴۰۵ (۲۸ نوامبر ۲۰۲۶) است. ساعت ۱۸ تا ۲۴ و نام باغ‌تالار عمارت نمونه‌اند. بعد از تعیین مکان، `coordinates` را به `{ lat: ..., lng: ... }` و `isVenueExample` را به `false` تغییر دهید. `dateTime` و `endDateTime` زمان شمارش معکوس و فایل تقویم را تعیین می‌کنند.


تصاویر عمارت و پاکت با ابزار داخلی ImageGen تولید شده‌اند. تصویر زوج از صفحه حذف شده است. پرامپت‌ها و مسیرهای خروجی در `ASSETS.md` ثبت شده‌اند. موسیقی از ویدیوی مرجع ارائه‌شده توسط کاربر استخراج شده است. فونت‌ها به‌صورت محلی بارگذاری می‌شوند. متن دعوت‌نامه از فونت IranNastaliq استفاده می‌کند.

امکانات: پاکت چندلایه با بازشدن سه‌بعدی و گذار سفید به عمارت، آتش‌بازی طلایی، تاریخ خراشیدنی با پشتیبانی صفحه‌کلید، متن نستعلیق ایرانی با چیدمان دو ستونه، شمارش معکوس چپ‌به‌راست، دکمه‌های مسیریابی قابل تنظیم و فایل تقویم. تنظیم کاهش حرکت سیستم نیز رعایت می‌شود.
