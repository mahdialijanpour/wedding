# دعوت‌نامهٔ عروسی سینا و نادیا

React + Vite، راست‌به‌چپ، مناسب موبایل و دسکتاپ.

```sh
npm install
npm run dev
npm run build
```

در صورت اشغال بودن پورت پیش‌فرض:

```sh
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5187 --strictPort
```

اطلاعات مراسم در `src/config.js` قرار دارد. تاریخ اصلی شنبه ۷ آذر ۱۴۰۵ (۲۸ نوامبر ۲۰۲۶) است. ساعت ۱۸ تا ۲۴ و نام باغ‌تالار عمارت نمونه‌اند. بعد از تعیین مکان، `coordinates` را به `{ lat: ..., lng: ... }` و `isVenueExample` را به `false` تغییر دهید. برنامهٔ مراسم نیز در همین فایل قابل تغییر است. `dateTime` و `endDateTime` زمان شمارش معکوس و فایل تقویم را تعیین می‌کنند.

برای پاسخ مهمان در واتساپ، `rsvpPhone` را با شمارهٔ بین‌المللی بدون علامت + تنظیم کنید. تا قبل از آن، فرم فقط متن پاسخ را کپی می‌کند و هیچ پاسخی به سرور ارسال نمی‌شود.

تصاویر با ابزار داخلی ImageGen تولید شده‌اند و تصویر عروس و داماد جنبهٔ هنری دارد، نه عکس واقعی زوج. پرامپت‌ها و مسیرهای خروجی در `ASSETS.md` ثبت شده‌اند. موسیقی از ویدیوی مرجع ارائه‌شده توسط کاربر استخراج شده است. فونت‌ها به‌صورت محلی بارگذاری می‌شوند.

امکانات: پاکت متحرک، عمارت شبانه با ذرات نور، تاریخ خراشیدنی با پشتیبانی صفحه‌کلید، شمارش معکوس، برنامهٔ جشن، دکمه‌های مسیریابی قابل تنظیم، فایل تقویم و آماده‌سازی پاسخ حضور. تنظیم کاهش حرکت سیستم نیز رعایت می‌شود.
